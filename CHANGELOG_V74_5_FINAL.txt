V74.5 ACCURACY-FIRST ADDITIONS
1. Market Regime Brain
   - TRENDING UP / TRENDING DOWN / RANGE-MIXED / TRANSITION / HIGH VOLATILITY.
   - Index breadth, agreement, dispersion and VIX context are used.
2. India VIX Intelligence
   - Level, daily change, short-horizon acceleration, risk regime, session z-score/percentile when enough observations exist.
   - VIX is contextual/risk evidence only; never a standalone trade signal.
3. Data Quality Gate
   - PASS / CAUTION / BLOCK based on provider status and freshness metadata.
   - Stale/unavailable inputs reduce confidence or block trade-ready states.
4. Adaptive Weighting
   - Evidence weights change by market regime instead of using one fixed weighting set.
5. Setup Lifecycle
   - FORMING / CONFIRMING / READY / WATCH / WEAKENING / INVALIDATED.
6. Temporal Confirmation / Debounce
   - A raw READY setup must persist for two adaptive snapshots before V74.5 exposes it as qualified.
7. Contradiction Resolver
   - Independent evidence is combined and conflict ratio is measured.
8. Signal Quality vs Execution Quality
   - Direction/setup quality is separate from liquidity/spread/R:R execution quality.
9. Uncertainty + Abstention
   - High uncertainty, low execution quality, bad data, blockers or mixed evidence produce WAIT / NO TRADE.
10. Late / Overextension Guard
    - Chasing beyond instrument-specific trigger-distance thresholds is rejected.
11. Cross-Market Context
    - Uses only available verified global rows; missing feeds are omitted rather than fabricated.
12. Correlation Guard
    - Warns when apparently separate qualified setups are correlated exposures.
13. Market Memory
    - Material regime/risk/data/VIX/best-setup state changes are stored using existing V74.3 durable memory infrastructure.
14. What Changed
    - Regime, risk, VIX, data gate and best-setup state deltas are exposed.
15. Accuracy / Calibration Contract
    - Observed accuracy remains separated from confidence.
    - Walk-forward, no future leakage, realistic spread/slippage and champion/challenger shadow-first promotion are explicit policies.
