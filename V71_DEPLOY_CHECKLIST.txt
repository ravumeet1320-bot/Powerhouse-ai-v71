4. Render start command: uvicorn app:app --host 0.0.0.0 --port $PORT
5. Preserve existing Upstox credentials/environment variables.
6. Add/keep V71 environment variables from .env.example.
7. For durable audit/history on Render, set POWERHOUSE_V71_DB_PATH to a persistent mounted disk path.

   GET /api/health -> HTTP 200 and version 71.0
   GET /api/v71/status -> version 71.0
   GET /api/v71/universe -> expected/observed coverage visible
